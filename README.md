# 🎮 Universal Remote for Flipper Zero

**Fast universal remote for popular TVs and air conditioners.**

This remote was created to replace the standard universal remote in Flipper Zero. Instead of cycling through hundreds of signals, it checks only the most popular models in an optimal order, turning your TV on or off in seconds.

---

## 📥 Installation & Usage

1. Download the `TV-AC-V3.ir` file from this repository.
2. Connect your Flipper Zero to your computer.
3. Copy the file to the SD card at:  
   `infrared/assets/TV-AC-V3.ir`
4. Open the **Infrared** app on your Flipper Zero.
5. Select **Universal Remotes** → **Load from Library File** → choose `TV-AC-V3.ir`.

---

## 📋 Supported Devices

| # | Brand | Models / Notes |
| :---: | :--- | :--- |
| 1 | **Samsung** | Most models with Samsung32 protocol |
| 2 | **LG** | Models with NEC protocol (24LJ4840, etc.) |
| 3 | **Sber (Salut TV)** | Sber TVs and Salut TV set-top boxes |
| 4 | **Haier** | L42C1180 and similar models |
| 5 | **TCL** | 43S446, Google TV and others |
| 6 | **Panasonic** | Models with Kaseikyo protocol (N2QAYB001109) |
| 7 | **Xiaomi** | Most models (RAW signals) |
| 8 | **Philips** | Models with RC5 and RC5X protocols |
| 9 | **Hisense** | 55U6K, 55K3201GUWUS, 32A4HAU |
| 10 | **Medion** | Models with RC5 protocol |
| 11 | **Toshiba AC** | Air conditioners (NECext, address 01 FF) |
| 12 | **Midea AC** | Air conditioners (RAW signals) |
| 13 | **LG AC** | Air conditioners (NECext, address 81 66) |

---

## 🎯 How to Use

1. Open **Infrared** → **Universal Remotes** → **Load from Library File**.
2. Select `TV-AC-V3.ir`.
3. Press the desired button (e.g., `Power`).
4. Flipper Zero will cycle through signals from Samsung, LG, SberTV, Haier, etc.
5. Once your TV responds — press `OK` to stop the cycle, or just wait until the remote finds the correct signal.

# 🎮 Universal Remote для Flipper Zero

**Быстрый универсальный пульт для популярных телевизоров и кондиционеров.**

Этот пульт создан, чтобы заменить стандартный универсальный пульт Flipper Zero. Вместо того чтобы перебирать сотни сигналов, он проверяет только самые популярные модели в оптимальном порядке, благодаря чему выключает или включает телевизор за секунды.

---

## 📥 Установка и использование

1. Скачай файл `TV-AC-V3.ir` из этого репозитория.
2. Подключи Flipper Zero к компьютеру.
3. Скопируй файл на SD-карту по пути:  
   `infrared/assets/TV-AC-V3.ir`
4. Открой на Flipper Zero приложение **Infrared**.
5. Выбери **Universal Remotes** → **Load from Library File** → выбери `TV-AC-V3.ir`.

2. Выбери `universal_remote.ir`.
3. Нажми нужную кнопку (например, `Power`).
