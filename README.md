# 🎮 Universal Remote для Flipper Zero

**Быстрый универсальный пульт для популярных телевизоров и кондиционеров.**

Этот пульт создан, чтобы заменить стандартный универсальный пульт Flipper Zero. Вместо того чтобы перебирать сотни сигналов, он проверяет только самые популярные модели в оптимальном порядке, благодаря чему выключает или включает телевизор за секунды.

---

## 📥 Установка и использование

1. Скачай файл `TV-AC-V3.ir` из этого репозитория.
2. Подключи Flipper Zero к компьютеру.
3. Скопируй файл на SD-карту по пути:  
   `infrared/assets/universal_remote.ir`
4. Открой на Flipper Zero приложение **Infrared**.
5. Выбери **Universal Remotes** → **Load from Library File** → выбери `TV-AC-V3.ir`.

## 🎯 Как использовать

1. Открой **Infrared** → **Universal Remotes** → **Load from Library File**.
2. Выбери `universal_remote.ir`.
3. Нажми нужную кнопку (например, `Power`).
4. Flipper Zero начнёт по очереди отправлять сигналы от Samsung, LG, SberTV, Haier и т.д.
5. Как только твой телевизор отреагирует — нажми `OK`, чтобы остановить перебор, или просто подожди, пока пульт найдёт правильный сигнал.
